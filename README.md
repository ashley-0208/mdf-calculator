# MDF Calculator

A simple Python project for practicing basic programming concepts.

## 🚀 Features

- Basic arithmetic operations (add, subtract, multiply, divide)
- Simple and clean structure
- Beginner-friendly
- No external libraries required

## 🛠️ Installation & Usage

Clone the repository:

```bash
git clone https://github.com/ashley-0208/mdf-calculator.git
```

Navigate to the project folder:

```bash
cd mdf-calculator
```
Run the program:

```bash
python main.py
```

## 📌 Requirements

- Python 3.x

## 🎯 Purpose

This project is built for learning and practice. It helps you:

- Understand basic Python structure  
- Practice input and output handling  
- Build a simple CLI tool
